# Last-Mile Delivery Operations Analytics

## 1. Project Overview

Last-Mile Delivery Operations Analytics is a MySQL database project developed to manage and analyze delivery operations.

This project focuses on customer details, orders, drivers, vehicles, and delivery information.

It helps understand delivery performance, order details, driver activities, and vehicle utilization using SQL queries.

## 2. Project Objectives

- Manage customer information.
- Store and manage order details.
- Maintain driver and vehicle records.
- Track delivery status and delivery time.
- Analyze delivery performance.
- Generate useful business insights using SQL.

## 3. Technologies Used

- MySQL 8.0
- MySQL Workbench
- SQL
- GitHub

## 4. Database Name

delivery_project

## 5. Database Tables

This project contains five tables:

| Table Name | Description |
|---|---|
| Customers | Stores customer information |
| Orders | Stores customer order details |
| Drivers | Stores driver information |
| Vehicles | Stores vehicle details |
| Deliveries | Stores delivery information |

## 7. Project Analysis

The following analysis is performed using SQL:

1. Total number of orders.
2. Orders by service type.
3. Orders by priority.
4. Total order value.
5. Delivery status analysis.
6. Average delivery time.
7. Driver performance analysis.
8. Vehicle utilization.
9. Multiple delivery attempts.
